# ADR 0018: AI/エージェント・セキュリティ（OWASP LLM/Agentic Top 10）

- 状態: 受理（改正: [[0037]] [[0039]]）
- 日付: 2026-07-04
- 背景: ハーネスはツールと取得文書を扱う。間接注入と過剰 agency が死活。製品 RLS/課金は置かない。
- 決定: **defense-in-depth**（`criteria/security-policy.yaml`）:
  1. **間接注入対策**: 取得文書/ツール出力はデータ扱い（命令にしない・spotlighting）。
  2. **最小権限**: プロンプト由来の経路を信用しない。hooks から Task を点火しない。
  3. **高リスク操作は human-in-the-loop**（削除/外部送信/秘密を含む実行/無制限再起）。
  4. **出力安全**: ツール呼び出しは構造化検証。OPA は `deny` 空だけを見る（`allow` 完全ルールを信用しない）。
  5. **消費上限**: run 毎 step 上限 + ループガード。cycle 再起は人間の PR マージ後だけ（[[0039]]）。
  6. **供給網**: プラグイン/MCP は pin。機密はプロンプトに載せない。
  7. **検出**: `security-reviewer`（既定 Opus 5・高リスクは3ファミリー）。
- 結果: プロンプト/ツール/取得を制御する agent 側の責務。
